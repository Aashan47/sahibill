        How SahiBill decides
        
              
          
            • Muse Spark Open reads the photo, field by field, and copies what is printed. It does not decide anything.
              • 
          
            • Code holds back any field that breaks a rule every genuine bill follows: readings that do not add up, dates outside the billing month, charges that do not total.
              • 
          
            • Code applies the rules: NEPRA's Consumer Service Manual (revised 26 November 2025) and the domestic tariff for 2026. Every number in the verdict is computed here.
              • 
          
            • When the bill cannot settle a question, SahiBill says so and names the record to ask for.
